# 首页项目证据文案待确认稿

更新时间：2026-08-31

这份文案先用于确认，不直接替换首页。目标是让每个项目在首页就回答三个问题：解决了什么、我做了什么、推进到什么状态。

## A 柱补盲

现版：`复杂规则 / 跨系统协同 / 安全体验`

建议：`定义盲点影像与开门预警的触发、退出和冲突规则，协同座舱、仪表与研发完成方案收口，已推进开发。`

## 称重与余粮体系重构

现版：`软硬件协同 / 状态规则 / 端云职责`

建议：`针对温漂、粮食密度和宠物干扰重构称重与余粮体系，明确固件、米家插件与云端职责，OTA6 方案已进入版本开发。`

## 米家智能宠物项圈

现版：`用户洞察 / 产品定义 / 硬件取舍`

建议：`结合 5 组用户深访与跨品类替代研究识别机会，在通信、续航、重量、防水与生态约束下收敛 V1，完成新品预立项方案。`

## PoopNow

现版：`推荐策略 / 独立交付 / AI 辅助开发`

建议：`为驾车、步行和地铁设计差异化推荐策略，调用 DeepSeek 与高德地图 API 独立完成小程序开发；核心功能已完成，正在等待微信平台审核。`

## 确认后怎么使用

- 首页每个项目保留一条完整证据句，不再只放能力标签。
- 项目详情抽屉同步使用同一套事实与项目状态。
- PoopNow 的状态统一按详情页口径写为“核心功能已完成，正在等待微信平台审核”，避免首页“已上线”与详情页“审核中”冲突。
