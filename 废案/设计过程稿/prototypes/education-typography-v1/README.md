# 教育经历文字排版候选稿 v1

## 设计读法

这是给招聘方快速扫描的个人作品集教育段。它延续全站的米白纸面、黑色颤线和少量钴蓝，但把视觉主体交给真实文字本身。稿件使用原生 HTML/CSS，不依赖框架，也没有把文字烘焙到图片里。

设计拨杆：`DESIGN_VARIANCE 8`、`MOTION_INTENSITY 4`、`VISUAL_DENSITY 3`。本稿保持静态，结构通过大小、错位、留白和一条连接线完成，不加入自动动画。

## 构图理由

- 东华大学放在左上，年份和校名承担主视觉，强调当前的机械硕士训练。
- 上海海事大学放在右下，字号与位置降低一个层级，但仍保留完整学院、学位信息。两段经历不是同款卡片，也不是时间轴。
- 钴蓝只出现在两段文字之间的连接线和端点，表示学习经历如何继续流向产品判断。页面没有蓝色点阵、校徽或具象插画。
- 页面没有档案纸、印章、胶带、票据或表格。背景只复用全站纸纹，正文文字均为 HTML。

## 移动端折叠思路

`768px` 以下改为严格单列：东华先完整呈现，蓝线横向下折，上海海事向右缩进后出现。年份缩小为可扫读的两级标题，学校名称允许自然换行，学院、学位和研究方向保持普通文本流。这样不会依赖横向拖动，也不会把两段重新做成卡片。
