## 修改顺序

1. 改文字：以 [`确认文案.md`](确认文案.md) 为准，并同步修改 `../index.html`。
2. 改视觉：只使用 [`视觉母版/`](视觉母版/) 和 `../assets/` 下的网页运行素材。
3. 改动效：先读 [`交互规则.md`](交互规则.md)，再修改 `../app.js` 与 `../styles.css`。
4. 新方案尚未确认时放入 `../待确认/`；明确否决或被替代后再移入 `../废案/`。
