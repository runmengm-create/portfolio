# 开屏概念方案二：图案变成 Renee

## 核心

初始状态不显示大标题，只有一组母版气质的二维颗粒图案。点击后，图案不是淡出，而是重新排列、拉伸和合并，连续变成 `Renee`。

## 动效节奏

1. 图案状态：碎片做轻微平移，蓝线和节点保持安静响应。
2. 点击节点：蓝线先收紧，成为形变的牵引轴。
3. 图案重组：黑色碎片沿二维路径移动，逐步对应到 `R`、`e`、`n`、`e`、`e` 的字形结构。
4. 字形完成：颗粒纹理保留在字母内部，蓝线变成轻微的下划路径或从最后一个 `e` 延伸出去。
5. 停留片刻后，字形再接入进入后的页面路径。

## 实现原则

- 用 SVG path morph 做连续形变，不做“图案消失＋文字淡入”。
- 全程只使用二维平移、旋转、路径形变和透明度变化。
- 不使用透视、阴影、立体折叠或大幅缩放。
