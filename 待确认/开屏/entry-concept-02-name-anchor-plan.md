# 开屏概念方案二（名字锚点版）

## 视觉

- `Renee` 本身是开屏的主视觉，不用抽象字母或符号替代名字。
- 蓝线从大写 `R` 的下方自然延伸出来，保持母版的细、松、低对比路径。
- 右侧只保留几个小颗粒形体，作为被路径带动的视觉碎片。

## 动效

1. `Renee` 静止出现，蓝线从 `R` 的边缘慢慢长出。
2. 蓝线经过两个 `e` 的下方时，右侧小形体逐个回应。
3. 鼠标靠近节点，蓝线轻微收紧，小形体向路径靠近。
4. 点击节点，蓝线快速向右延展，碎片被依次带走。
5. 进入后的第一条蓝色路径接住这条线，完成开屏呼应。

## 强度

方案二的大胆感来自“名字本身被激活”，而不是放大黑色块面或加粗蓝线；视觉仍然保持母版的克制和二维平面感。
